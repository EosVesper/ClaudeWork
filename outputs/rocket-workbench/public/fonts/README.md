# 公式字体

- `stix-two-text.woff2`、`stix-two-text-italic.woff2`：STIX Two Text（400 字重）的子集，包括拉丁、希腊、上下标和 ṁ。
- `stix-two-math-ops.woff2`：STIX Two Math 的运算符子集（√ ≈ ∗ ≤ ≥ ∑ ∂ 等），按 `unicode-range` 补充上面两个字体缺少的字形。

来源：Google Fonts 仓库 `ofl/stixtwotext`、`ofl/stixtwomath`。版权归 The STIX Fonts Project Authors，按 SIL Open Font License 1.1 发布，许可证见 `OFL.txt`。子集用 fontTools 生成。
