# 火箭发动机热力计算工作台 v1.2.0 交付说明

课程大作业二《火箭发动机热力计算》的程序交付版。程序由 C 求解器和本机网页界面组成，分析对象是朱雀三号（天鹊-12B / 天鹊-15B）和长征十号乙（YF-100K 系列）。

## 一、快速开始

| 用途 | 操作 |
| --- | --- |
| 实时计算（Windows x64） | 安装 Node.js 20 或以上版本，双击 `Start-Workbench.cmd`，浏览器会自动打开 `http://127.0.0.1:8732/` |
| 只看界面和结果 | 用浏览器直接打开 `工作台页面回放.html`。回放页收录了三组课设预设的实算结果，无需安装任何软件 |
| 自动测试 | 在本目录运行 `npm test`，会调用真实求解器，共 8 项 |
| Linux 或 macOS | 安装 WineHQ 后同样可以运行 `npm start` 和 `npm test`，见 README |

用默认预设，依次点「运行计算」和「计算工况区间」，应能看到下列结果：

| 主视觉 | 页面顶部 | 喷管内的粒子从燃烧室流向出口，过喉部明显加速，颜色由炽白渐变为橙红；切换发动机后喷管形状和读数随之变化 |

## 四、已验证与未验证

已验证（在 Linux 云端，通过 WineHQ 11.0 运行同一批 Windows 程序）：

- 求解器输出与原 Windows 实算 JSON 逐位一致。
- `npm test` 8/8 通过。
- 三组预设、流量为 0、热损失扫描、固体算例、工况对比，以及深浅两套主题的界面都逐页截图检查过；回放页离线可用。
- 理想解与 Cantera 3.2 独立计算的偏差在 0.2% 以内。

未验证，请交付前补做：

- **没有在真实 Windows 电脑上运行过。** 请在一台 Windows 电脑上做一次冒烟测试：双击启动脚本，跑一遍上面的检查清单，再运行 `npm test`。
- 回放页里显示的求解耗时（约 7 秒）是在 Wine 下测得的，Windows 上会更快。

## 五、已知局限与待办

1. **β（其他支路流量份额）的文献出处待补。** 默认值 0.09 来自第一次大作业「参数确定」中引用的一项液氧甲烷燃气发生器方案（65.8 / 699.4 kg/s）。作业中这条的参考文献写着「后续补齐」，网上也没有检索到原文。
2. **涡轮排气速度比 c_GG/c（0.30 / 0.45 / 0.65）是标明的课程假设**，没有天鹊系列的实际数据。
3. **TQ-15B 的 3500 m/s 与 β = 0.09 不相容。** 面积比从 50 扫到 130，名义值仍低于公开值。真空型可能分流更小，或者涡轮排气被利用了。这一点建议写进报告的「验证与分析」。
4. **李斌（2022）的原文没有取得**，YF-100K 的 1250 kN、302 s 是从二手资料交叉确认的。
5. **推力对比不是独立验证。** 预设流量由「公开推力 ÷ 公开比冲」换算而来（天鹊系列再乘以 1 − β），页面上已经标注。
6. 模型是稳态准一维的。三维图按面积比旋转、沿对数压强排布，不代表真实的喷管型面。
