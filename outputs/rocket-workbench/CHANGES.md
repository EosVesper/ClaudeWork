# 改版说明（相对 ChatGPT/Codex 交付版）

C 求解器源码与可执行文件未改动。所有修改都在 Node 层（`analysis.mjs`、`engine.mjs`）和前端（`public/`）。

## 验证与可信度

- **理想区间不再兼作「理论区间」**：原区间以热损失 Q（无出处的 300 kJ/kg）为唯一损失项，基准算例本身就是上界，中点检查必然通过。现在拆成三层：
  - 理想热力区间：平衡流 ↔ 冻结流。
  - 实际性能包络：燃烧效率、扩张损失、边界层，以及燃气发生器整机口径，因子带出处并可编辑。
  - 公开值对照。
- **热损失 Q 降为可选敏感性输入**，默认 0，并说明了再生冷却的热回收。
- **公开值对照**：
  - 修复：流量为 0 时比冲也被标成「工况不同」（比冲与流量无关）。
  - 新增：公开推力 ÷ 公开比冲隐含的总流量，自动识别推力对比不独立的情形（YF-100K），以及流量口径导致的偏差（天鹊 B 型为 91%）。
  - 新增：所需综合效率。
  - 公开值依据重新核对：招股书第 1-1-210 页、蓝箭 2023 年和 2025 年通报，口径写进表格。
- **独立代码复核**：新增 `tools/cantera_crosscheck.py`。用 Cantera 3.2 独立求解三组预设，与 C 求解器偏差不超过 0.2%，结果在验证页列出，并纳入 `npm test`。
- **数值检查**：熵偏差、喉部声速条件由求解器直接施加，改标「按构造满足」，与可以失败的真正校核区分开。

## 可视化

- 压强比坐标改为十进制刻度（1、10⁻¹、10⁻²），取代原来的 0.266、0.071 等。
- 压强、密度彩色图改用对数色标。
- 彩色剖面新增「相对平衡流差值」模式，使用发散色标；热损失三维曲面在差值模式下改为显示相对 Q = 0 的变化。
- 三维喷管更名为「面积–压强旋转体」，图中注明轴向不是真实长度。

## 可用性

- 输入修改后，结果区顶部显示过期横幅；页眉注明当前是单工况还是含区间。
- 状态表改为 5 位有效数字，量纲一的单位不再显示成「1」。
- 修复「临界截面」卡片换行、组分名被截断的问题。
- 总览卡片注明是理想值，并附名义交付比冲。
- 求解过程页说明 Brent 法的停止条件，解释残差为什么会回升。

## 导出与复现

- 剖面 CSV：喉部面积比改为 1，亚声速段留空（求解器在这些位置输出 0）。
- 完整 JSON 附带当前损失因子、包络和公开值判定。
- Linux/macOS 可通过 WineHQ 运行，`ROCKET_WINE` 可指定启动器。
- 新增 `tools/build-replay.mjs`：用真实求解器重新生成离线回放页和 `reference-data/`。
- `npm test` 从 6 项增至 8 项，全部通过（WineHQ 11.0）。

## 第二轮（结合第一次大作业资料）

- 「其他支路流量份额 β」默认改为第一次大作业的 0.05 / 0.09 / 0.13，并注明依据（燃气发生器 65.8 kg/s ÷ 整机 699.4 kg/s = 9.41%）。改动后，TQ-12B 名义整机比冲 296.0 s，与公开值 293 s 相差 1.0%。
- 自动识别「主推力室流量 = 公开推力 ÷ 公开比冲 × (1 − β)」这种构造，把对应的推力对比标为不独立。
- 公开值超出包络时，给出可能原因的提示。TQ-15B 的 3500 m/s 与 β = 0.09、面积比 50–130 均不相容，说明真空型的支路份额可能更小，或涡轮排气被利用。
- 燃烧效率的说明注明第一次大作业的基准取值（η_c* = η_CF = 0.97，报告中自评偏保守）。
