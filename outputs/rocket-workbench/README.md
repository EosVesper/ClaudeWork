# 火箭发动机热力计算工作台

这是面向课程演示的 Windows 本地应用。界面通过本机 HTTP 服务调用 C/C++ 求解器，包含自带的九系数热力数据库、输运数据库、CoolProp 运行库和已编译的 x64 求解器。

## 启动与数据导出

1. 在安装了 Node.js 20 或以上版本的 Windows x64 电脑上，双击 `Start-Workbench.cmd`。浏览器会在服务就绪后打开 `http://127.0.0.1:8732/`。也可以在项目目录运行 `npm start`。
2. 选发动机预设或固体配方。表单的压强以 MPa 和 kPa 输入，服务统一换算为 Pa。液体工况的主推力室流量可填 0，界面会将绝对推力与尺寸显示为缺失。
3. “运行计算”计算当前模型，并由喉后截面面积生成可旋转的轴对称喷管图。“计算工况区间”另外计算两种膨胀模型的边界和中点。图谱页可切换到热损失工况曲面。总览支持实算剖面及关键截面，过程页支持温度与残差试算表。
4. 图表可导出 PNG，剖面、收敛过程、区间工况和对比数据可导出 CSV。完整 JSON 包含输入、原始 C 输出、逐次试算、数值检查与公开数据比对。计算输入和结果留在本机。关闭启动窗口可停止服务。

## 工况区间和验证口径

- 液发基础区间固定推进剂、供给状态、室压、混合比、出口条件、流量和环境压强。计算绝热与 Q 上限下的化学平衡及组分冻结，逐指标取四个成功边界算例的最大、最小值。随后用 Q 上限一半另算两组中点并检查区间包含关系。
- 可在高级设置填写有依据的 Q 上限。默认 300 kJ/kg 是用于观察影响的课程敏感性假设，以每千克产物计。区间描述所选模型的有限样点，实机摩擦、分离、非均匀性和辅助支路还需要额外模型或测量。固体算例使用绝热条件下两种膨胀模型。
- 数值校核包括燃烧室焓求根、候选表质量闭合与熵复算、适用时的喉部声速条件、喷管截面总焓与熵，以及推力方程复算。求解器告警或缺失剖面会在界面提示。
- 验证页还用相同室态与出口约束独立计算定比热理想气体解析参考。单列显示解析解与变物性数值解的差异。
- 天鹊 B 型按蓝箭航天的公开设计／额定值比照。YF-100K 使用研究院作者的公开文献作为系列参考。主推力室和公开单机整机口径的差异随数据呈现。
- 彩色剖面与三维曲面由稳态准一维采样数据生成。三维喷管图沿对数压强轴布置圆形截面，横向坐标在流量已知时以米表示，流量未知时按喉半径归一化。三维工况曲面沿归一化膨胀进度和单位质量热损失布点。颜色对应截面平均热力状态，物理轴向坐标和径向流场需要另给几何与更高维求解。

### 默认预设的复算记录

基准为绝热化学平衡，区间按 Q = 0 和 300 kJ/kg 的平衡与冻结工况生成。三个预设的中点工况数值均落在对应指标区间内。

| 预设与指标 | 基准 | 计算区间 | 公开值 | 基准偏差 |
| --- | ---: | ---: | ---: | ---: |
| TQ-12B 海平面推力（kN） | 1006.15 | 960.05–1006.15 | 1000 | +0.61% |
| TQ-12B 海平面比冲（s） | 323.96 | 309.12–323.96 | 293 | +10.57% |
| TQ-15B 真空推力（kN） | 1109.48 | 1055.46–1109.48 | 1183 | −6.21% |
| TQ-15B 真空比冲（s） | 367.83 | 349.91–367.83 | 356.90 | +3.06% |
| YF-100K 海平面推力（kN） | 1331.26 | 1235.10–1331.26 | 1250 | +6.50% |
| YF-100K 海平面比冲（s） | 321.24 | 298.04–321.24 | 302 | +6.37% |

TQ-12B 海平面比冲和 TQ-15B 真空推力的公开值在区间外。整机验证仍需对应额定工况的流量口径、支路和损失数据。YF-100K 采用文献中的系列数据，长征十号乙同工况单机数值尚未核实。

## 复现与重新编译

- `npm test` 会调用真实求解器，检查三组课设预设的边界、中点、守恒、收敛和公开偏差，也覆盖固体算例及缺失流量。
- `solver\build-msvc.cmd` 可用已安装的 Visual Studio C++ x64 工具重建带逐次试算输出的求解器。原 MinGW 构建方法见 [求解器说明](solver/README.md)。
- 被调用的求解器使用 `--trace` 导出实际能量方程试算，`--list-engine-data` 导出预设。原有数值方法与工况预设沿用课程工程。
